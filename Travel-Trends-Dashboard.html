Travel Trends Dashboard

A small data lab exploring travel trends over time with Python, focusing on clear charts, transparent code and actionable insights.

Project context

This dashboard prototype is part of my data & digitalization portfolio and demonstrates how I use Python to turn raw travel data into readable visual patterns.

  • Stack: Python, pandas, seaborn/matplotlib
  • Format: Jupyter Notebook, static charts
  • Portfolio: GitHub Pages case study

Key visualizations

The dashboard focuses on a small set of strong charts instead of many decorative visuals. Each chart answers a concrete question about travel trends.

Seasonality line chart

This chart shows how demand for a specific destination changes over time, revealing pronounced summer peaks and off-season dips that are relevant for planning and marketing.

Destination comparison

A bar chart compares destinations within the same timeframe, giving a quick overview of which locations are currently most attractive.

Heatmap of patterns

The heatmap emphasizes repeated patterns and anomalies, supporting more nuanced questions such as: which periods are surprisingly strong or weak compared to the general trend.

Code & implementation

The main purpose of this project page is to make the implementation visible: how the data is loaded, prepared and turned into charts with Python.

Data loading & preparation

The notebook starts with a clear, reproducible data pipeline: reading the source file, selecting relevant columns and creating tidy structures. 


import pandas as pd
import seaborn as sns
import matplotlib.pyplot as plt

# Load data (example: Google Trends export or tourism statistics)
df = pd.read_csv("data/travel_trends.csv")

# Basic cleaning and selection
df["date"] = pd.to_datetime(df["date"])
df = df.sort_values("date")

# Filter for one destination and aggregate by month
mallorca = (
    df[df["destination"] == "Mallorca"]
    .groupby(pd.Grouper(key="date", freq="M"))
    .agg({"interest_score": "mean"})
    .reset_index()
)

print(mallorca.head())

Chart generation in Python

Charts are generated directly from the cleaned data and exported as PNG files, which are then integrated into this portfolio page. 


sns.set(style="whitegrid")

plt.figure(figsize=(10, 5))
sns.lineplot(
    data=mallorca,
    x="date",
    y="interest_score",
    color="#d98fa1"
)

plt.title("Mallorca interest over time")
plt.xlabel("Date")
plt.ylabel("Interest score")

plt.tight_layout()
plt.savefig("assets/travel-seasonality-line.png", dpi=150)
plt.close()
