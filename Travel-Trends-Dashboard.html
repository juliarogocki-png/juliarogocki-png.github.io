Travel Trends Dashboard

A small data lab exploring travel trends over time with Python, focusing on clear charts, transparent code and actionable insights.

Focus: Data analysis, trend visualization, Python charts

Role: End-to-end analysis, notebook implementation, portfolio integration

View project on GitHub Back to projects

Project context

This dashboard prototype is part of my data & digitalization portfolio and demonstrates how I use Python to turn raw travel data into readable visual patterns.

  • Stack: Python, pandas, seaborn/matplotlib
  • Format: Jupyter Notebook, static charts
  • Portfolio: GitHub Pages case study

Key visualizations

The dashboard focuses on a small set of strong charts instead of many decorative visuals. Each chart answers a concrete question about travel trends.

Seasonality line chart

This chart shows how interest in specific hashtags changes over time, revealing pronounced peaks and off-season dips that are relevant for content planning and marketing.

Destination comparison

A bar chart compares hashtags within the same timeframe, giving a quick overview of which topics are currently most attractive.

Heatmap of patterns

The heatmap emphasizes repeated patterns and anomalies, supporting more nuanced questions such as: which categories are surprisingly strong or weak compared to the general trend.

Code & implementation

The main purpose of this project page is to make the implementation visible: how the data is loaded, prepared and turned into charts with Python.

Chart 1: Seasonality line chart

Simulated seasonal interest for top travel hashtags over 12 months. 


"""
Chart 1: Seasonality line chart
Output: assets/travel-seasonality-line.png
"""

import os
import pandas as pd
import seaborn as sns
import matplotlib.pyplot as plt
import numpy as np
from io import StringIO

os.makedirs("assets", exist_ok=True)

csv_data = """hashtag,posts_millions,views_billions,category,source
#travel,26.3,217.8,General,tiktokhashtags.com
#traveltiktok,5.4,49.0,TikTok,tiktokhashtags.com
#travellife,2.5,16.3,Lifestyle,tiktokhashtags.com
#adventure,4.3,40.7,Activity,tiktokhashtags.com
#vacation,6.9,40.6,General,tiktokhashtags.com
#nature,21.7,132.3,Activity,tiktokhashtags.com
#traveltips,0.408,10.5,Information,tiktokhashtags.com
#travelblogger,0.589,4.4,Influencer,tiktokhashtags.com
#travelmemories,0.589,4.0,General,tiktokhashtags.com
#travelphotography,0.756,3.0,Photography,tiktokhashtags.com
#holidaycountdown,1.3,11.6,Planning,tiktokhashtags.com
#viaje,2.0,20.3,Travel,tiktokhashtags.com
#naturevibes,1.7,8.3,Nature,tiktokhashtags.com
#dubai,24.0,176.5,Destination,tiktokhashtags.com
#summer,24.3,171.3,Seasonal,tiktokhashtags.com
#holidayvibes,1.3,8.1,Holiday,tiktokhashtags.com
#asmr,18.8,937.5,Content,tiktokhashtags.com
#motivation,40.5,374.3,Content,tiktokhashtags.com
#fyp,616.2,49600.0,Trending,tiktokhashtags.com
#explore,72.3,1200.0,Trending,tiktokhashtags.com
#foryou,707.5,29000.0,Trending,tiktokhashtags.com"""

df = pd.read_csv(StringIO(csv_data))
sns.set(style="whitegrid")

top_hashtags = df.nlargest(5, "views_billions")["hashtag"].tolist()
months = pd.date_range("2025-01-01", periods=12, freq="ME")

np.random.seed(42)
sim_data = []
for i, hashtag in enumerate(top_hashtags):
    base = df[df["hashtag"] == hashtag]["views_billions"].values[0]
    phase = i * np.pi / 4
    for t, month in enumerate(months):
        seasonal = np.sin(2 * np.pi * (t / 12) + phase)
        noise = np.random.normal(0, base * 0.05)
        value = base * (0.6 + 0.4 * (seasonal + 1) / 2) + noise
        sim_data.append({
            "date": month,
            "hashtag": hashtag,
            "views_billions": max(0, value)
        })

sim_df = pd.DataFrame(sim_data)

plt.figure(figsize=(10, 5))
for hashtag, grp in sim_df.groupby("hashtag"):
    plt.plot(
        grp["date"],
        grp["views_billions"],
        marker="o",
        label=hashtag,
        linewidth=2
    )

plt.title("Simulated seasonal interest for top hashtags", fontsize=14, fontweight="600")
plt.xlabel("Month", fontsize=12)
plt.ylabel("Views (billions)", fontsize=12)
plt.legend(title="Hashtag", fontsize=10, title_fontsize=11)
plt.tight_layout()
plt.savefig("assets/travel-seasonality-line.png", dpi=150)
plt.close()

#explore,72.3,1200.0,Trending,tiktokhashtags.com

sns.set(style="whitegrid")

df_norm = df.copy()
df_norm["posts_norm"] = df_norm["posts_millions"] / df_norm["posts_millions"].max()
df_norm["views_norm"] = df_norm["views_billions"] / df_norm["views_billions"].max()

heatmap_matrix = df_norm.groupby("category")[["posts_norm", "views_norm"]].mean()

plt.figure(figsize=(8, 6))
sns.heatmap(
    heatmap_matrix,
    annot=True,
    fmt=".2f",
    cmap="YlOrRd",
    cbar_kws={"label": "Normalized intensity (0–1)"}
)

plt.title("Hashtag categories: normalized performance patterns", fontsize=14, fontweight="600")
plt.xlabel("Metric", fontsize=12)
plt.ylabel("Category", fontsize=12)
plt.tight_layout()
plt.savefig("assets/travel-heatmap.png", dpi=150)

In a next step, this analysis could be extended into an interactive dashboard, for example with filters for destinations, time ranges or traveler segments. For this portfolio stage, the combination of notebook, charts and this case page already demonstrates my approach to data‑driven work.
