Project

Travel Trends Dashboard

A Python-based dashboard concept developed to explore patterns, seasonal shifts and changing consumer interest in travel-related topics through data visualization.

Overview

This project was designed as a data-focused case study that combines research thinking with visual analysis. The idea was to use structured data exploration to better understand how interest in travel-related topics changes over time.

It also serves as a portfolio project to demonstrate how Python can be used not only for data handling, but also for clear and decision-oriented visual communication.

Question

How do travel interests shift across topics, time periods and possible seasonal patterns, and how can these changes be made visible in an understandable way?

Goal

The goal was to build a dashboard concept that makes trends easier to compare and interpret through a combination of structured metrics and visual outputs.

Focus

The main focus of the project is the combination of Python, trend analysis and data visualization in a format that remains clear, practical and visually coherent.

Planned Visualizations

  • Time-based comparisons to show shifts in interest over time.
  • Charts for comparing categories or travel-related topics.
  • Heatmaps to highlight seasonal or recurring patterns.
  • Dashboard elements for quick scanning and structured interpretation.

Approach

The project follows an analytical workflow: defining the question, structuring the data, identifying relevant dimensions for comparison and translating the findings into visuals that support interpretation rather than just display numbers.

This reflects the kind of work I am interested in most: connecting research questions, structured analysis and digital presentation in one coherent output.

Why this project

I wanted to include a project that shows my interest in data-driven topics and my ability to think through visual analysis beyond static reporting.

Technical Perspective

The dashboard is intended to demonstrate practical Python usage for analysis workflows, comparisons and visual outputs such as heatmaps and charts.

Portfolio Role

Within the portfolio, this project complements the more UX-focused and process-focused case studies by adding a clear analytics and visualization perspective.

What I learned

This project reinforces the importance of choosing visual formats that help people understand patterns, not just inspect data. It also reflects my interest in combining analysis, structure and communication in digital work.
