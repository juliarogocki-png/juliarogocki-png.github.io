Project

Digitalization Process

A workflow and digitalization project focused on replacing manual evaluation and reporting steps with a more structured, traceable and scalable process.

Process Design Digitalization GUI / Python Context

Overview

The project was initiated to improve an existing evaluation and reporting workflow by replacing fragmented manual steps with a more centralized and digitally supported structure.

Key goals included reducing manual effort, improving data quality, increasing traceability, enabling central data storage and making evaluations faster and more reliable overall.

Challenge

Problem

The existing process relied heavily on manual handling, fragmented Excel files and limited automation. This made evaluation and reporting more time-consuming, less transparent and harder to scale.

Objective

Goal

The aim was to design a clearer target workflow supported by a stable data structure, automated analysis functions and a more user-friendly reporting process.

Contribution

My Role

I contributed to GUI development and to the broader structuring of the project context, helping translate requirements into a workable concept and a clearer system logic.

Scope

Project Scope

  • Analysis of the existing setup, including macros, add-ins and Excel files.
  • Definition of requirements for heatmaps, time series views and reporting outputs.
  • Work on data management structures and import processes.
  • Support for a Python-based backend and GUI concept using PySide6.
  • Consideration of reporting outputs such as PDF and PowerPoint export.
Structure

Project Structure

The project was structured across several connected areas including project management, functional requirements, data management, Python backend, user interface, reporting, testing and introduction.

This structure helped break a complex workflow into clearer modules and responsibilities across technical, analytical and organizational parts of the project.

Technical Direction

Implementation Context

The documentation points toward a shared development setup with Git, Python-based functionality and a desktop GUI built with PySide6 to make the application accessible for non-technical users.

Planning

Milestones

The planning included milestones and task groups around project setup, analysis and specification, data import, backend logic and reporting preparation.

Early visible work packages included projectauftrag erstellen, planning, Git setup, analysis of macros and add-ins, Excel file review and data import preparation.

Reflection

Open Questions

Remaining questions included file storage strategy and the future handling of visual outputs, for example via Power BI or static graphics.

Timeline

Gantt Overview

The Gantt plan made progress and dependencies easier to track by linking assigned tasks, start dates, planned end dates and actual end dates in one view.

It visualized work packages such as project setup, coordination, analysis and data basis preparation, making the implementation path more transparent across the early project phase.

Takeaway

What I Learned

This project strengthened my understanding that digitalization depends not only on technical implementation, but also on process clarity, requirement definition and coordination across stakeholders and outputs.

It also showed how closely data structures, interface decisions and reporting logic are connected when building solutions that need to work reliably in everyday practice.
