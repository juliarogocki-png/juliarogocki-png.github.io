Desktop sessions show the higher observed conversion

In this dataset, 8.3% of desktop searches result in a booking, compared with 6.0% of mobile searches. This is an observed association, not evidence that device type causes the difference.

Key finding

The clearest difference appears in conversion.

Travel distance and stay length provide useful context, but their distributions overlap considerably across device groups.

Interpretation: The booking-rate chart shows the clearest descriptive difference. Travel distance and stay length do not visibly separate desktop and mobile searches to the same extent.

import pandas as pd
import matplotlib.pyplot as plt
from matplotlib.ticker import PercentFormatter

booking = (
    df.groupby("device")["is_booking"]
      .agg(["mean", "count"])
      .reindex(["Desktop", "Mobile"])
)

fig, ax = plt.subplots(figsize=(8, 5), facecolor="#f7f6f2")

bars = ax.bar(
    booking.index,
    booking["mean"],
    width=0.55,
    color="#d98fa1"
)

for bar, rate, n in zip(
    bars,
    booking["mean"],
    booking["count"]
):
    ax.text(
        bar.get_x() + bar.get_width() / 2,
        rate + 0.002,
        f"{rate:.1%}\n(n={n:,})",
        ha="center",
        va="bottom",
        fontweight="600"
    )

ax.set_title("Booking Rate by Device Type")
ax.set_xlabel("Device Type")
ax.set_ylabel("Booking Rate")
ax.yaxis.set_major_formatter(PercentFormatter(1))
ax.set_ylim(0, 0.10)

plt.tight_layout()
plt.savefig("visuals/booking_rate.png", dpi=300)
plt.close(fig)
