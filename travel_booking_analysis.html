Exploring Booking Conversion by Device Type

An exploratory and inferential analysis of hotel-search sessions, examining whether desktop and mobile users differ in booking conversion after accounting for selected characteristics of the search context.

Focus: Booking conversion, device comparison, UX-oriented data analysis

Role: Data preparation, exploratory analysis, logistic regression and interpretation

Tools: Python, pandas, seaborn, matplotlib, scikit-learn

Back to projects

Project context

This project uses hotel-search and booking records to investigate whether the device used during a search is associated with booking conversion. The workflow combines descriptive visualization with a logistic regression model. The model does not prove causality; it tests whether the observed device-related pattern remains after selected control variables are included.

The dataset originates from Expedia's Hotel Recommendations competition, published through Kaggle. It contains anonymized records of customer search behaviour, including search attributes, device information, package status, clicks and bookings. The original competition data include records from 2013 and 2014; the data are a random selection and are not representative of Expedia's overall business statistics.

  • Dataset: Hotel-search and booking records
  • Outcome: Search resulted in a booking or not
  • Predictor of interest: Mobile versus desktop device
  • Output: Three visualizations and a regression model
  • Data source: Expedia Hotel Recommendations on Kaggle

Research question

Are hotel-search sessions on desktop and mobile devices associated with different booking-conversion rates, and does this association remain after accounting for selected characteristics of the search context?

The analysis begins with a descriptive comparison of booking rates between device groups. It then examines travel distance and requested stay length to understand whether the search contexts show visible differences or substantial overlap. Finally, logistic regression is used to estimate the association between device type and booking status while controlling for selected search features.

This structure separates three analytical questions: What do the raw group differences look like? Which contextual variables appear relevant? And does the device-related difference remain visible once those variables are considered together?

Analysis results

The descriptive analysis compares booking conversion and travel-planning characteristics across desktop and mobile search sessions.

Key finding

Desktop sessions show the higher observed booking conversion.

In this dataset, 8.3% of desktop searches result in a booking, compared with 6.0% of mobile searches. This is a difference of 2.3 percentage points. The result identifies an association in the observed data; it does not show that device type itself causes the difference.

Interpretation: The clearest difference between the two groups concerns conversion. Travel distance and planned stay length provide useful context but do not visibly separate desktop and mobile users to the same extent.

Next analytical step

Because booking status is binary, logistic regression is the appropriate method to estimate the probability that a search results in a booking. The model will test the device association while including selected contextual variables.

The dependent variable is is_booking. The main predictor is is_mobile, where 0 represents desktop and 1 represents mobile. The control variables include package status, the number of adults, the number of children, the number of rooms searched and the derived stay length. Missing values are handled before modelling, and numeric variables are standardized so that the coefficients can be compared more easily.

The most important model output is the coefficient or odds ratio for is_mobile. An odds ratio below 1 would indicate lower booking odds for mobile sessions relative to desktop sessions after adjustment. An odds ratio close to 1 would suggest that the raw booking-rate difference is largely accounted for by the included contextual variables. Statistical significance should be assessed using confidence intervals or p-values rather than inferred from the coefficient alone.
