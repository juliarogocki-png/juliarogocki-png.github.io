Exploring Booking Conversion by Device Type

An exploratory and inferential analysis of hotel-search sessions, examining whether desktop and mobile users differ in booking conversion after accounting for selected characteristics of the search context.

Project context

From search behaviour to conversion

This project uses hotel-search and booking records to investigate whether the device used during a search is associated with booking conversion. The workflow combines descriptive visualization with logistic regression.

The model does not prove causality. It tests whether the observed device-related pattern remains after selected contextual variables are included.

  • Outcome: booking or no booking
  • Main predictor: mobile versus desktop
  • Context: travel distance and stay length
  • Output: three visualizations and a regression model

Data source: Expedia Hotel Recommendations on Kaggle

Research question

Are booking rates associated with device type?

Are hotel-search sessions on desktop and mobile devices associated with different booking-conversion rates, and does this association remain after accounting for selected characteristics of the search context?

The analysis begins with a descriptive comparison of booking rates. It then examines travel distance and requested stay length to understand whether the search contexts show visible differences or substantial overlap. Finally, logistic regression estimates the association between device type and booking status while controlling for selected search features.

This structure separates three questions: What do the raw group differences look like? Which contextual variables appear relevant? And does the device-related difference remain visible once those variables are considered together?

Analysis results

Desktop sessions show the higher observed conversion

In this dataset, 8.3% of desktop searches result in a booking, compared with 6.0% of mobile searches. This is an observed association, not evidence that device type causes the difference.

Key finding

The main difference appears in conversion, not in the visible search context.

Travel distance and stay length provide useful context, but their distributions overlap considerably across device groups.

Interpretation: The booking-rate chart is the clearest result. The two distribution charts are useful as contextual diagnostics, but they should be refined before being treated as polished evidence.

Don’t show just the result

Show the code behind the analysis

A short excerpt from the Python workflow used to calculate the booking rates and create the visualization. The complete analysis is available in the linked GitHub repository.

analysis.py
import pandas as pd
import matplotlib.pyplot as plt

booking_rate = (
    df.groupby("device_type")["is_booking"]
      .mean()
      .mul(100)
      .reset_index(name="booking_rate")
)

fig, ax = plt.subplots(figsize=(10, 6))
ax.bar(
    booking_rate["device_type"],
    booking_rate["booking_rate"],
    color="#d98fa1"
)

for index, value in enumerate(booking_rate["booking_rate"]):
    ax.text(index, value + 0.25, f"{value:.1f}%", ha="center", weight="bold")

ax.set_title("Booking Rate by Device Type")
ax.set_ylabel("Booking Rate")
ax.set_xlabel("Device Type")
ax.set_ylim(0, 9)
plt.tight_layout()
plt.savefig("visuals/booking_rate.png", dpi=180)
plt.show()
